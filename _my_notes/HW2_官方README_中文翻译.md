# 练习 2：轨迹生成与 PID 控制

在本练习中，你将学习如何生成航点（waypoint）轨迹，并控制机器人在航点之间的运动。首先，你要学习如何生成保证运动平滑的航点；随后定义控制律来跟踪该轨迹。

### 控制流水线

你的任务是补全一条流水线的一部分，该流水线由航点生成、逆运动学（IK）计算和 PID 控制组成。流水线结构如下：

1. **航点生成：** 基于一组目标关键点，使用课上介绍的五次样条（quintic spline）时间缩放方法，生成由中间航点构成的轨迹。
2. **逆运动学（IK）：** 在上一练习中实现，用于把航点从工作空间映射到关节空间。
3. **PID 控制：** 期望关节角与当前关节角之差（跟踪误差）被送入 PID 控制器，控制器计算出合适的控制信号。
4. **MuJoCo 仿真：** 生成的控制信号通过 `data.ctrl[:]` 直接作为关节力矩施加到电机上。物理引擎步进，从而模拟机器人朝目标航点运动。

# 练习 3：训练航点跟踪策略

在本练习中，我们将进入马尔可夫决策过程（MDP）的仿真，并训练一个强化学习（RL）策略来跟踪随机选取的航点。

与上一练习相比，流水线也发生了变化，结构如下：

1. **观测：** 环境构造一个包含当前环境状态（机器人 & 目标）的观测向量，发送给 RL 智能体。
2. **动作预测：** RL 智能体以 **10 Hz**（每 0.1 秒）的控制频率预测一个归一化动作，范围 `[-1, 1]`。
3. **动作处理：** 环境接收归一化动作，将其转换为机器人物理极限范围内的关节位置目标。
4. **MuJoCo 仿真步进：** 这些目标位置被写入 `data.ctrl`，由 MuJoCo 在内部转换为目标关节力矩。MuJoCo 每 0.002s（500 Hz）步进一次；在环境向 RL 控制器索取新动作（10 Hz）之前，会连续步进 50 次（`ctrl_decimation = 50`）。
5. **奖励计算：** 每个控制步（即 50 个仿真步）之后，测量新的末端执行器跟踪误差，计算奖励，并把新状态返回给 RL 智能体，如此循环。

### 重要概念

- `np.clip(a, a_min, a_max)`：把数组的取值裁剪到给定范围内（常用于限制关节位置）。
- **原地数组修改：** 修改作为 `data` 对象属性（如 `mujoco.MjData`）的数组时，应使用切片（如 `[:]`）原地修改数组，让物理引擎能检测到变化，而不是覆盖整个数组引用。

# HW3 单方块抓取 · 按键教学版参考轨迹

这组文件是**按键驱动**的参考轨迹：脚本每一拍只按一个键（1 cm 移动，或夹爪 0.10），
所以视频里能直接看到"这一拍按了哪个键"，可以照着复原。
它不是人手遥操作，作业提交请用自己录的数据；这里只当教学参考。

- 场景：单方块 + 障碍 + 箱子，`seed 0`，成功率 1/1
- 总拍数：**263 拍**（10 Hz → 原速 26.3 秒；0.5× 慢放 54.6 秒）
- 数据：`ethz-robot-learning-2026/hw3_imitation_learning/datasets/expert_ref/keyed/2026-11-04_10-37-37/`

## 按键说明（来自你的 `hw3/keymap.json`）

| 按键 | 动作 |
|---|---|
| `K` | 张开夹爪 +0.10 |
| `J` | 闭合夹爪 −0.10 |
| `↑ / ↓` | 末端 z 上 / 下 1 cm |
| `← / →` | 末端 x 左 / 右 1 cm |
| `W / S` | 末端 y 前 / 后 1 cm |
| `·` | 这一拍不按键（等机械臂稳定） |

> 如果你重新跑了 `configure_keys.py`，按键会变，需要重新生成视频。

## 12 个阶段的连按序列

| # | 阶段 | 步 | 连按序列 | 要点 |
|---|---|---|---|---|
| 01 | 张开夹爪 | 0–16 | `K×17` | 先把夹爪开到最大 |
| 02 | 抬高到 z≈0.20 | 17–29 | `↑×13` | 先升高再平移 |
| 03 | 从左侧绕过障碍 | 30–82 | `←×6 ↑×1 S×28 W×18` | 走 x≈−0.28 走廊 |
| 04 | 对准方块正上方 | 83–87 | `→×5` | top 视角对 XY |
| 05 | 只降 Z 到 z≈0.04 | 88–108 | `↓×21` | 夹爪保持张开 |
| 06 | 分步闭合夹爪 | 109–127 | `J×15 ·×4` | 小步闭合，停一下再抬 |
| 07 | 抬 5–10 cm 验证 | 128–147 | `↑×20` | 方块跟手 = 抓住了 |
| 08 | 绕回障碍左侧搬运 | 148–184 | `←×4 ↑×1 W×31 →×1` | 保持 z≈0.20 |
| 09 | 移到箱子上方 | 185–197 | `→×7 W×1 →×1 W×1 ↑×1 ...` | 微调箱中心 |
| 10 | 送进箱子再松手 | 198–212 | `↓×15` | 方块进到箱壁以内 |
| 11 | 分步张开释放 | 213–235 | `K×15 ·×8` | 方块落到箱底 |
| 12 | 抬臂退回 | 236–262 | `↑×18 →×1 ↑×1 W×1 ·×6` | 避免刮箱沿 |

## 怎么用它练

1. 先 0.5× 看一遍，再按阶段跟练：**先只练 01–07**（对齐 + 抓取），熟了再练 08–12。
2. 每拍只按一个键；视频里 10 拍 = 1 秒，别连按。
3. 序列是"节奏模板"：方块/障碍位置每个 episode 都随机，实际移动次数会差几个，
   看着 `top` 和 `left_wrist` 随时微调，不要死背数字。
4. 抓取段的节奏：下降到底 → `J` 连按 15 次 → 等 4 拍 → `↑` 抬起来确认方块跟手。

## 重新生成

在 `ethz-robot-learning-2026/hw3_imitation_learning` 目录下：

```bat
.venv\Scripts\python.exe ..\..\hw3_demo_keyed.py --seed 0 --video
.venv\Scripts\python.exe ..\..\hw3_annotate_video.py datasets\expert_ref\keyed\<时间戳>
```

`--speed 0.25` 可以更慢（文件更大）。seed 0/1/2/4 都能成功；seed 3 的布局会让
夹爪把方块压进桌面导致物理爆炸，换个 seed 即可。
